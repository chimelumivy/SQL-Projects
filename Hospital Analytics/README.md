An end-to-end healthcare data analytics project exploring hospital operations, patient admissions, diagnoses, and readmission patterns using a synthetic hospital dataset.

Tools: Microsoft SQL Server (SSMS), SQL, Power BI, and Excel.

Objectives:
Validate and clean hospital data.
Analyse admissions, diagnoses, and readmissions.
Calculate key hospital performance indicators (KPIs).
Develop SQL views and interactive Power BI dashboards.
Generate insights to support data-driven healthcare decisions.

Project Status: In Progress
